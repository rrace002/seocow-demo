# All Sites Inventory

Spreadsheet of NearMe OS Website Factory / Netlify team sites.

## Open in Google Sheets

1. Open [Google Sheets](https://sheets.google.com) → **Blank spreadsheet**
2. **File → Import → Upload** → choose `all-sites-inventory.xlsx` (or `.csv`)
3. Import location: **Replace spreadsheet** → Import data

Or from a published raw CSV URL:

```
=IMPORTDATA("https://raw.githubusercontent.com/rrace002/seocow-demo/cursor/sites-inventory-127e/inventory/all-sites-inventory.csv")
```

## Columns

Site name, primary Netlify link, category, positioning, type, pages, domain target, staging flag, page title, PR, PR URL, branch, Netlify admin, alt URLs, notes.
